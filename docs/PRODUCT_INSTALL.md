# 0.3.7 安装与开始使用

当前 APK：0.3.7-preview / versionCode9，Android11+，包名 cn.xindong.junshi，73,929,517 字节，研发 Debug 签名。详细操作见 [使用教程](USER_GUIDE_0.3.7.md)，实际结果见 [测试报告](UI_TEST_REPORT_20261015.md)。

## 覆盖安装

从 deliverables/xindong-junshi-debug.apk 复制到手机，通过系统文件管理器点击安装；按系统提示允许这次安装来源。已有版本直接覆盖，**不要卸载**，卸载会丢失本机资料及 Keystore 密钥。若系统阻止，保留原提示并由本人处理，不绕过安全机制。

也可由本人连接手机、开启并确认 USB 调试，核对 adb devices 中自己的设备序列号后执行：

```powershell
adb -s <本人核对的设备序列号> install -r deliverables/xindong-junshi-debug.apk
```

本轮仅在 API35 模拟器安装及核对哈希成功，红米未连接；旧版0.3.5正常覆盖升级记录为历史，不等于新版已验收。独立 G1 验证程序是另一个包，无需用它日常生成回复。

## 登录与第一次回复

1. 首次注册本机账号，输入名称、至少6位密码和确认密码；已有资料用原账号密码登录，密码自行保管，不交给测试人员。
2. 建立或选择主播及观众。四个底部入口为“军师、聊天、档案、我的”；顶部资料卡切换当前档案。
3. “聊天”页自主粘贴历史，或选择截图、文件、媒体；导入后核对身份、方向、正文及从旧到新顺序，再确认入库。未提供历史明确缺失。
4. “我的 → 模型与组件”添加真实 HTTPS 接口、模型、Key、容量、人民币价格和核验来源，保存接口后再保存本主播配置。两个 Skill 默认开启、Jev默认关闭；按自己意愿阅读并确认云端范围与组件说明。保存设置不调用 AI。
5. “军师”页填写最新对方原文，连续消息用“添加一条”逐条填写，填入原文后显示核对项；全部确认后“确认最新消息并分析”。也可展开“基于现有历史分析”主动生成。缺配置会明确报错，不显示假回复。
6. 选择候选、编辑分段、逐条复制，自己在微信输入发送。实际发送原文另行确认记录；复制不等于发送，草稿不自动成为口吻样本。

只用粘贴历史和 App 内分析无需开启无障碍。需要前台可见消息读取时，到“我的 → 微信前台读取”，由本人授权、选择档案并启用本次读取；OCR仍须核对，不能读微信全部历史或后台无通知内容。完整步骤见使用教程。

## 数据与费用

本机账号支持“我的 → 修改密码”及退出锁定，无密码找回和跨设备同步。导出为当前观众资料明文 ZIP，不含模型Key，无整包恢复；自行保管。删除观众/账户要求输入名称。未保存草稿可能在进程结束后丢失。

“我的 → 费用与预算”展示预留及当前主播调用明细，初始100元额度在预估将达到时提醒和暂停；增加额度须本人确认。双Skill、长历史分块和格式修复可能有多次收费，未知用量保留预留。手机/桌面/服务商账单需人工核对。

本轮无新增真实AI调用，100组批次保持停止，52对记录含失败、人工评分0。新版真实接口和红米前台读取/撤权/长期测试仍待执行。只安装与整理材料不自动恢复付费测试。
