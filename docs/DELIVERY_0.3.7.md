## 具体改动

暖白、珊瑚色与深墨色替换旧配色，增加本地品牌图形及对话插画，重新安排字级、留白、输入框和操作按钮。登录页突出账号密码；军师页突出最新消息输入；档案使用头像、真实资料计数和分组表单；我的页将模型、读取、预算、资料与指南组织为分组入口。候选显示编号、风格、分段正文和编辑操作，底部面板保留逐条编辑与复制。

首次历史可从剪贴板粘贴。最新消息用“粘贴原文”和“添加一条”整理；输入后才显示三个核对项，全部确认仍是提交前提。低频历史分析、实际发送反馈和保存报告改为整行折叠入口。退出账号、切换页面的异步重绘崩溃已修复，并通过原有工作流回归。

本机账号注册、登录、改密、数据隔离、历史导入校对、媒体原件、长期记忆、完整历史引擎、费用规则和手动发送保留。双 Skill 默认开启，Jev 可选且默认关闭。没有增加服务器、生产依赖或真实模型请求。
