# 心动军师 · 0.3.6 使用说明

这是可安装试用的原生预览版。支持本机独立账号、聊天材料整理和真实模型接口；真实 AI 质量与红米长期稳定性尚未完成验收。Android 11 及以上，产品包名 `cn.xindong.junshi`。独立 G1 验证程序不属于日常产品入口。

## 安装与登录

安装 `deliverables/xindong-junshi-debug.apk`。已有版本直接覆盖安装，**不要卸载**，卸载会删除本机资料与设备密钥。研发 Debug 签名不等于正式上架版。

首次选择“创建你的本机账号”，输入账号名称、至少 6 位密码并再次确认。以后输入相同账号名称和密码登录，也可以选择已有账号。账号名称去除两端空格、不区分英文字母大小写，禁止重复注册；旧同名账户可从列表按标识选择。

“我的 → 修改密码”要求当前密码；改密保留已有资料。“退出并锁定账户”停止生成和读取，再次进入需登录。各账号、各主播、各观众分别保存资料。同名观众不会自动合并。**当前无密码找回、云同步或换机恢复**，请自行保管密码和导出文件。

## 四个入口

| 页面 | 用途 |
|---|---|
| 军师 | 核对最新对方消息、生成候选、编辑复制、查看完整分析、记录实际发送内容 |
| 聊天 | 粘贴/文件/截图/媒体导入、逐条校对、查找与整理已确认历史 |
| 档案 | 备注、偏好、明确边界、历史缺口、标签、长期事实与矛盾处理 |
| 我的 | 管理主播观众、修改密码、模型组件、费用、读取权限、资料管理与指南 |

先创建主播和观众。点击页面顶部资料卡可以切换；每次确认与当前微信聊天是同一个人。只有一个主播、一个观众时会自动选中，但消息归属仍需本人核对。

## 首次提供聊天记录

1. 在“聊天 → 粘贴文字”粘贴复制内容，每条消息另起一行，点击“导入待校对区”。也可选择“截图OCR”批量选图，或“文件与媒体”导入 UTF-8 文字和原件。
2. 在“2 校对导入批次”打开待校对批次。逐条修正正文，选择主播/观众与类型，核对时间；未知时间可以留空。截图中的标题、按钮、输入框文字要跳过。
3. 确认本批属于当前观众，确认从旧到新顺序，并逐条确认正文与说话人，最后“确认入库”。未经校对不会参与 AI。
4. 在“3 已确认历史”查找原文、校正、回看来源、调整顺序。搜索和分页只影响显示，分析仍处理全部已确认的可用历史；未提供的部分保持缺失。

结构化粘贴或文件支持四列 TSV：`时间<TAB>主播或观众<TAB>TEXT<TAB>正文`，时间可空。JSON 支持消息数组或 `{"messages":[...]}`，行包含 body，可含 speaker/time/kind；导入的 ID、已核对标志不会直接信任。

图片、表情、语音、视频原件会加密保存，可填写完整描述或转写并核对。当前没有自动语音转写或视频理解。原件预览限 32MiB，超限可导出原件核对；保存及导出不按此限制截断。文字文件单次限 16MiB。

## 模型与费用

进入“我的 → 模型与组件 → 添加接口配置”，填写完整 HTTPS 请求地址、模型标识、自己的 API Key、窗口/输出容量和人民币价格来源。保存接口只做本地检查，不发网络测试请求。还须“保存本主播配置”才对实际生成生效。

狗头军师和恋爱大师默认开启，由所选生成模型执行分析后再生成候选。Jev 当前默认关闭，可以后续添加独立 TypeSafe 接口再启用；DeepSeek Key 不能代替 Jev 凭据。已开启组件缺失配置或失败会明确停止，不静默省略。

阅读云端发送范围与组件说明，自行决定是否授权。发送范围包括当前观众的已确认历史、档案、已核对媒体描述以及主播真实已发送的口吻样本；未确认的整屏 OCR 不直接上传。Key 本机加密保存，不进入导出，不要发给别人。

每轮双 Skill 常规至少涉及多个模型请求，长历史分块和必要格式修复可能增加费用。允许的格式错误每个组件最多一次额外计费修复，修复结果仍严格校验；未知网络用量不会按免费处理。“我的 → 费用与预算”可核对设备月度预留和当前主播明细，达到初始 100 元额度会提示并暂停，增加额度须本人确认。手机、桌面及服务商账单需核对，不能保证账户全部消费都被本机自动统计。

## 日常获得回复

在“军师 → 对方说了什么？”逐条粘贴最新尚未回复的对方原文。连续消息用“增加对方连发消息”，按发生顺序填写。确认当前观众、正文方向和最新未入库状态，点击“确认最新消息并分析”。先保存已核对消息，再执行真实分析；缺配置或授权时会说明原因，不显示假候选。

也可展开“基于现有历史分析”，填写本轮需求并主动生成。全部可用历史参与分析，容量不足时分批处理；系统不知道你未提供的历史。

选择候选后进入“你的草稿”，修改每一条并逐条复制，自己去微信输入和发送。App **不会自动填写或发送微信**。选择、编辑、复制都不会自动成为口吻样本；发送后展开“记录实际发送内容”，填写最终实际原文并确认，才会记录学习。每次记录一条。

“展开完整军师分析”或“已保存的分析”可查看事实、推测、未知、组件状态、历史覆盖及原文依据。模型自评分不是质量验收分数。

## 可选微信前台读取

在“我的 → 微信前台读取”打开系统无障碍设置，由本人授权“心动军师”。回 App 选择正确档案，开启本次前台自动读取，并显示悬浮球。手动进入已授权微信聊天，等待页面稳定；读取只覆盖当前可见文字，不能读取后台无通知消息或全部历史。

用悬浮球的“核对最新消息并分析”直接返回 App。在军师页选择“选择识别文字”，只选最新对方消息，跳过标题、按钮和主播文字，随后修正 OCR 错字、消息边界，并完成三个核对项。读取不可靠时直接粘贴原文。

切换聊天、滚动、进入其他应用、锁屏或撤权会清除或取消旧状态；切换档案、锁屏、撤权后需要重新开启自动读取。回 App 核对时尽量用悬浮球直接跳转。这个路径已有旧版有限真机证据，新版红米复测和长期稳定性仍待完成。

## 资料管理与当前限制

“我的 → 资料管理”可导出当前观众完整资料，ZIP 含聊天、原件和报告明文，不含 Key，自己选择保存位置并妥善保管。写入失败可能留下不完整 ZIP，以 App 成功提示为准；当前没有 ZIP 一键恢复。删除观众或账户要求输入完整名称，无法撤销。外部导出和剪贴板需自行管理。

常用表单跨页面与屏幕旋转可保留，按观众分别保存。尚未保存的模型、接口和批次草稿只保留在当前进程；强行结束进程或退出登录可能丢失。真实账号密码与模型 Key 不进入系统界面恢复数据。

100 组质量及普通模型对照批次按用户要求停止，现有 52 对生成记录包含失败，96 个 AI 审阅输出不等于人工合格，人工评分为 0。没有宣称达到 95/100，也未新增付费调用。已知问题和实际测试层级见本次交付报告。
