# 心动军师原生界面规范 · 0.3.7

2026-10-15。依据用户重新美化界面的要求，见 CHANGE_REQUEST_20261015_UI.md。上一版截图与测试保存在 reports/ui-redesign/20261014；本规范描述当前实际代码。

## 视觉与信息层级

暖白页面、白色内容表面、珊瑚色操作、深墨色文字。减少重复描边与说明，把空间让给聊天输入和回复。本地品牌矢量和 Compose Canvas 对话插画不依赖远程图片，装饰不进入无障碍阅读树。系统中文字体随系统字号缩放。

军师页：紧凑联系人卡 → 品牌引导 → 最新消息输入 → 核对与分析 → 首次历史/模型准备 → 可展开的历史分析与发送反馈。填写原文后展示三个核对项，任一未确认都不能提交；OCR行选择不会自动勾选。

我的页：账户资料及管理 → 回复助手分组 → 账户与资料分组。入口由图标、标题、简短说明与箭头组成；低频项进入二级页面。候选使用编号、风格、正文和编辑按钮，编辑面板支持逐段复制，由用户手动发送。

四项底部导航为军师、聊天、档案、我的。同名观众仍按稳定 ID 区分，切换范围清除旧任务。

## 操作与适配

登录最大480dp，主内容最大840dp，接口编辑最大720dp。居中限制行长；纵向滚动支持小屏、横屏与键盘，并列按钮用FlowRow换行。操作至少48dp，登录及最新分析按钮54dp；勾选整行可点，提供Checkbox语义。折叠入口提供展开状态和点击标签。

系统状态栏、手势区和输入法使用原生Insets。提交错误保留，接口错误回顶部。没有新增持续动画，系统关闭动画时主要流程仍可操作。

普通表单按观众隔离，在页面切换和Activity重建后保留；批次和接口草稿留当前进程。Key不进入saved-instance Bundle；取消、切换主播或退出清除接口草稿。进程结束可能丢失未保存内容。密码、Key及真实聊天不进入公开截图。

## 验证

verify_ui_contrast.py从实际Kotlin解析浅/深色32组启用状态文字和边框，文字4.5:1、边框3:1；不覆盖禁用态、系统UI或抗锯齿。

ProductUiTest检查真实账号、表单、导入、OCR核对、候选和配置流程。VisualUiTest在指定模拟器实际运行、截图并检查关键控件与导航触控目标，全部使用合成数据且不调用模型。布局矩阵覆盖375×812dp浅/深色、深色2倍字体、812×375dp横屏和800×1280dp平板，动画关闭。执行结果、失败与修正见UI_TEST_REPORT_20261015.md。
