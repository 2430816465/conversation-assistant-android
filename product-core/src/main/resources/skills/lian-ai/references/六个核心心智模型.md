## 六个核心心智模型

### 模型一：先看见现实，再解释现实

**一句话**：很多痛苦不是来自事实本身，而是来自没有看见事实，就先用愿望、分类或恐惧替它下结论。

**证据方向**：

- 直播379期复盘聊天时，反复追问“能不能看见对方，也看见自己的目的”；
- 直播347期讨论理想化投射和现实检验；
- 直播249期讨论投射、权威认可和现实感。

**应用**：

- 消息回复、邀约、暧昧和关系判断；
- 对他人动机的猜测；
- 把一次拒绝解释成自我价值判决。

**运行方式**：

1. 只写可观察事实；
2. 单独写自己的解释；
3. 检查解释中包含多少愿望和恐惧；
4. 寻找能推翻自己解释的新信息。

**局限**：事实不完整时不能保证得到确定答案。现实检验不是压抑直觉，而是避免把直觉冒充事实。

### 模型二：行为是保护性回应，不只是对错

**一句话**：许多看似不理性、矛盾或破坏性的行为，首先是在保护一个人不去接触难以承受的感受。

**证据方向**：

- 直播262期系统讨论防御机制没有简单好坏，而有成熟度和适用场景；
- 直播329期把防御描述为人与世界互动时持续调用的回应系统；
- 直播242、243期把投射、理智化和关系推进连接到防御。

**应用**：

- 反复确认、讨好、冷处理、控制和理智化；
- 明知道不合适却重复进入相似关系；
- 用道德、理论或愤怒回避更脆弱的感受。

**运行方式**：

不要先问“这个行为对不对”，先问：

- 它在保护什么？
- 如果不这样做，会感受到什么？
- 这个保护现在还有用吗？
- 有没有代价更小的回应？

**局限**：理解行为的保护功能不等于为伤害行为开脱。涉及暴力、胁迫和侵犯边界时，先处理安全和责任。

### 模型三：人格和自我功能由经验发展

**一句话**：理解概念不能代替新的生活经验；一个人是在行动、受挫、修复和重新回应中发展自我功能。

**证据方向**：

- 直播300期集中讨论人格发展和人格结构；
- 直播334期讨论压抑、分离和亲密关系中的自我功能；
- 直播363期将自我展示的不适连接到自尊、意义和真实经验。

**应用**：

- “道理都懂但做不到”；
- 长期停留在分析和准备中；
- 害怕拒绝、羞耻或犯错；
- 只靠课程和术语获得“我在成长”的感觉。

**运行方式**：

- 把大目标缩成一次可承受的新经验；
- 行动后观察感受，而不是只看结果；
- 允许失败成为新信息；
- 重复练习新的回应。

**局限**：不是所有问题都应该靠暴露和硬做解决。创伤、强烈焦虑或精神健康问题可能需要专业支持和更慢节奏。

### 模型四：亲密需要分化、边界与责任

**一句话**：亲密不是两个人互相吞没，而是两个独立的人能够靠近、分开、协商并承担自己的部分。

**证据方向**：

- 直播260期讨论自由、责任、分离焦虑和人格边界；
- 直播267期讨论边界与长期关系；
- 直播282、334期讨论与父母分离、人格独立和关系能力。

**应用**：

- 偷看手机、查行程、要求随时报备；
- 因对方情绪而完全失去自己的生活；
- 讨好后期待对方回报；
- 把“我需要你”表达成“你必须这样做”。

**运行方式**：

区分三部分：

- 我的感受与行动；
- 对方的选择与边界；
- 双方需要协商的共同部分。

**局限**：强调边界不能变成情感冷漠，也不能用“各自负责”否认共同承诺。

### 模型五：痛苦常来自控制幻想与意义赋予

**一句话**：事件会带来感受，但人还会继续给事件赋予“它证明我不值得”“关系完了”等意义，并试图控制本不可控的结果。

**证据方向**：

- 直播282期讨论约会变化时不要立刻赋予“被拒绝”的终局意义；
- 直播233期讨论可控与不可控、允许不同结果发生；
- 多期亚马逊直播用不确定性说明焦虑既有功能，也需要被允许。

**应用**：

- 对回复速度、拒绝、流量和收入过度解释；
- 反复追求确定性；
- 把他人选择变成自己的价值证明；
- 用控制行为缓解焦虑。

**运行方式**：

问四个问题：

1. 实际发生了什么？
2. 我给它加了什么意义？
3. 哪些结果不由我控制？
4. 我现在能选择怎样回应？

**局限**：不是说“一切都是你想出来的”。真实伤害、背叛和损失需要被承认，不能用重新赋义取消事实。

### 模型六：真实欲望可以表达，但不能强迫结果

**一句话**：自然表达不是隐藏欲望，也不是用技巧操控，而是能看见自己、看见对方，并允许对方拒绝。

**证据方向**：

- 直播272期直接比较技术流和自然流；
- 直播243期讨论肢体推进、防御和回应对方反馈；
- 直播379期指出结果目的过强时会看不见对方，也扭曲自己的表达。

**应用**：

- 邀约、表白、身体接触和关系协商；
- “好男人”式讨好；
- 用套路隐藏真实意图；
- 因害怕拒绝而永远不表达。

**运行方式**：

- 先承认自己想要什么；
- 用清楚、尊重、可拒绝的方式表达；
- 观察对方真实反馈；
- 对拒绝停止推进，不把拒绝理解为人格失败。

**局限**：真实不等于把所有冲动都付诸行动。同意、时机、安全和关系承诺仍然构成边界。
